Install

Grab the latest .deb from the releases page and install it — dependencies come along automatically.

Users

No Rust, no build tools, no manual steps.

sudo apt install ./bloqsync_*_amd64.deb

Then launch bloqsync, connect your monitors once, and hit Start.

From source

Build the app and bundle a package yourself.

git clone https://github.com/niemanma/bloqsync
cd bloqsync
./install.sh

Built to be extended

Bar models and effects are plain JSON — add your own by dropping in a file, or share it with everyone.

Bar models

Describe a bar's USB identification, LED count, edge distribution and protocol:

  • match — vendor / product / usage page
  • leds, left/top/bottom/right
  • protocol — report size, sections/frame, actions…

Own a different SyncLight size, or a different bar entirely? Add a model and open a PR.

Effects

An effect is a closed chain of colour points plus a movement — rendered to one colour per LED:

{ "points": [
  { "hue": 0.08, "sat": 0.85, "brightness": 1.0,  "duration": 50 },
  { "hue": 0.08, "sat": 0.85, "brightness": 0.12, "duration": 50 }
] }

Build one in the editor, or drop a JSON file under gui/animations/.

Get involved

Test it on your hardware, create profiles, add bar models, design effects, translate the UI — contributions and shared JSON are very welcome.
